# 可灵 4.0 猫咪与狗狗动作提示词（3 秒）

## 使用方法

- 在图生视频中选择 **Kling 4.0、3 秒、首尾帧**，将同一张猫咪或狗狗待机图设为首帧和尾帧。在本机 Demo 选择首尾帧模式后，尾帧留空会复用首帧。
- 每次复制一个完整的提示词块。文中的「输入首帧」指实际上传的图片，左、右均按观看者看到的画面方向。以下动作均以宠物趴卧的待机图为前提，按各条动作说明保留或自然调整支撑位置；其他姿态请按实际首帧修改。
- 猫咪使用「尾尖轻摆」时，首帧应能看到尾尖；蹭头动作用面向镜头、头部前方有活动空间的首帧。
- 狗狗动作须保留首帧里的耳型、口鼻长度和尾型。立耳、垂耳按原有结构自然运动；短尾、卷尾不改成长直尾。「尾根带动摇尾」和「开心摇尾迎人」要求尾根及可摆动的尾段清楚可见，迎人动作还需头部前方有少量前探空间；「抬爪求关注」和「下巴枕爪再抬头」要求前爪完整可见；舔鼻、轻喘使用嘴巴自然闭合的首帧，轻喘还需能看清口鼻。下巴枕爪使用原本抬头趴卧的首帧。
- 每条提示词描述动作的先后和衔接，片段总时长设为 3 秒。动作结束后回到待机姿态，便于接回待机画面。猫咪新版与新增狗狗提示词均待生成验证。

## 提示词结构与官方依据

依据[可灵 4.0 官方使用指南](https://kling.ai/quickstart/kling-4-model-user-guide)的 §2.2「Write Effective Prompts」和 §3.2「Keyframes」：用具体可见的细节描述运动；首尾帧示例会标明两张图片的作用，再描述中间过程。官方并未要求使用统一的长开场白。

本机 Demo 已通过独立参数提交时长和首尾帧，因此本文不在每条提示词中重复「生成 3 秒图生视频」「以输入尾帧为结束画面」等设置，也不逐项罗列图片中已有的毛色、花纹和五官。外观与场景延续用简短说明，动作结束后的自然收回则保留在具体动作过程中。这是针对本机用法的精简，并非官方禁止较长的提示词。

本文所有动作统一采用「场景 → 动作过程 → 动作表现要求 → 镜头与画面要求」的分段格式，便于独立复制。这是本文的整理方式，并非官方规定的固定小标题。

首尾帧相同有助于规划回到待机姿态，但不能保证生成视频无缝衔接，需逐条实测。[可灵 4.0 API 提示词指南](https://klingai.com/document-api/api/usage-guide/kling-4-0-prompt-guide)本次仍未能读取，不作为已核实的教材依据。

## 狗狗动作提示词

狗狗部分围绕听觉注意、主动嗅闻、摇尾招呼和向人寻求互动设计。摇尾由尾根带动，抬爪以整只前掌抬起和放下为主，耳朵按原有耳型随动作变化。每条只安排一个主要动作，连贯完成后回到首帧姿态。

### 1. 歪头听动静

```text
【场景】
延续首帧中狗狗的外观与背景，狗狗独自趴在原处，注意着镜头方向。

【动作过程】
狗狗像是注意到镜头方向的动静，目光集中，头部稍稍抬起。它保持鼻尖朝前，将头顶轻轻偏向画面右侧，带着专注的神情短暂停住，像是在辨认熟悉的招呼。

随后头部自然扶正，颈部放松，回到首帧的头部高度、趴卧姿态和视线。

【动作表现要求】
只做一次清楚的小幅歪头，侧倾与回正平顺连贯。耳根随注意力略微调整，立耳保留原有挺立形态，垂耳随头部侧倾自然下垂。两只前爪留在原处，胸腹和后半身维持趴卧，嘴巴保持首帧的自然状态。

【镜头与画面要求】
```
