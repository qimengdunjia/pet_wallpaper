# 车机宠物交互壁纸 PRD

根据 2026-11-18 提供的截图整理。所见内容从第 04 章开始，目标设备为车机，Demo 暂按 15.6 英寸横屏考虑。网页阶段验证素材生成。每只宠物上传一张清晰正面照，先生成该宠物的待机图，再以同一张待机图生成各方向的视频。

## 04 首次录入、多宠

### 4.1 首次录入

| 节点 | 车机规则 |
| --- | --- |
| 进入 | 无宠物时直接显示类型选择，无需先填写姓名或创建账号 |
| 选择 | 提供「猫咪」「狗狗」「猫狗都有」。选两种时分别提供上传猫照片和上传狗照片的入口 |
| 提交 | 点击「生成壁纸」创建宠物档案，发起照片生成请求 |
| 等待 | 播放猫狗追赶过场 |
| 完成 | 默认进入首选宠物或率先生成可用的宠物壁纸。另一只未完成时在列表显示「生成中」，就绪后可选 |

### 4.2 切换与新增

- 从按猫狗分类的列表选择已有宠物，加载对应的已完成资源。同种用短转场，跨种用追逐过场。
- 添加宠物时选择猫或狗并上传照片。保存独立 Pet ID、壁纸和热区动作资源，资源生成前无法触发对应动作。
- 正在生成的宠物在列表显示「生成中」，整套互动资源就绪后可切换。切换或新增失败时保留当前成功的壁纸。
- 宠物选择入口独立于壁纸画布，面板打开时优先响应面板点击。

### 4.3 过场设计

采用固定镜头、统一简洁背景，通过角色相对位移实现追逐。两只宠物持续奔跑，超越时视觉中心从一只平滑转移到另一只。首次录入首轮 10 秒，资产表将其拆成 3 秒先导和 7 秒等待循环。若资源未就绪，继续循环 7 秒等待段，先导只播一次。故事板提供了 0、2、4、7、9、10 秒的视觉参考。

## 05 屏幕热区与点击映射

横坐标按壁纸画布宽度归一化。状态栏、导航、功能按钮、安全弹层等画布外或盖在画布上的系统区域消费点击。

| 画面区域 | 横向坐标 | 参考中心 | 5.2 表内编号 |
| --- | --- | --- | --- |
| 左 | 0% ≤ x < 34% | 17% | Z2 |
| 中 | 34% ≤ x < 66% | 50% | Z3 |
| 右 | 66% ≤ x ≤ 100% | 83% | Z5 |

截图标题和第 6 章写五热区、猫狗各五段。5.1 示意图却标 Z2/Z3/Z4，坐标为 20–40%、40–60%、60–80%，并明确只作示意。5.2 与第 7 章可执行明细各给出左、中、右三种动作。本轮以 5.2 的画面三分区及第 7 章的动作细节生成六条猫狗交互视频。额外两区的边界、编号与动作待产品确认。

## 06 伸爪与探头动作

素材统一以中性待机姿态起始，然后抬爪或探头、停留或轻触、收回并恢复同一姿态。车机点击时选择预生成的视频播放。待机图为正面趴卧，正脸居中，身体约占画面六成，保留动作空间。交互背景由用户定义，同一宠物的三个方向共享背景、镜头和待机画面。

## 07 动画资产

全部目标规格为 1920 × 1080、16:9、24 fps。交互动作 4 秒，首尾帧应与待机图衔接。过场用简洁半写实场景，蓝天白云占约三分之二，绿地占约三分之一。

| 类别 | 素材 | 时长 | 动作和衔接 |
| --- | --- | --- | --- |
| 首次录入 | 追逐先导 | 3 秒 | 猫先从左侧跑入画面中间，狗随后进入。收在猫前狗后的奔跑姿态，接入等待段 |
| 首次录入 | 等待循环 | 7 秒 | 猫前狗后开始，狗先超到前方，猫再追到前方，回到首帧的位置和姿势。首尾连续 |
| 跨种切换 | 猫切狗 | 3 秒 | 当前猫在中央跑，目标狗从屏幕左边追上并占据中央，猫相对向左退出，奔跑不断 |
| 跨种切换 | 狗切猫 | 3 秒 | 当前狗在中央跑，目标猫从屏幕左边追上并占据中央，狗相对向左退出，奔跑不断 |
| 猫 | 左热区 | 4 秒 | 猫自身右前爪伸到画面左侧，肉垫轻触后原爪收回 |
| 猫 | 中热区 | 4 秒 | 猫自身左前爪伸向镜头正前方，肉垫轻触后收回 |
| 猫 | 右热区 | 4 秒 | 猫自身左前爪伸到画面右侧，肉垫轻触后原爪收回 |
| 狗 | 左热区 | 4 秒 | 抬头、微吐舌、摇尾。向目标画面区域探头，以鼻尖轻轻向上顶触后回到趴卧 |
| 狗 | 中热区 | 4 秒 | 抬头、微吐舌、摇尾。沿镜头轴向前探头，鼻尖微向上触碰，再恢复趴卧 |
| 狗 | 右热区 | 4 秒 | 抬头、微吐舌、摇尾。向目标画面区域探头，以鼻尖轻轻向上顶触后回到趴卧 |

「六段」按资产表的六条猫狗交互素材理解，过场另外逐段测试。切换流程图写跨种追逐 10 秒，资产明细给出独立 3 秒素材，Demo 按资产明细生成，跨种播放时长待车机交互定版。表内两条切换的动作主语和名称对调，本次以切换方向为准，让目标物种跑到中央。狗左右热区的参考图与文字方向不完全一致，统一按观众所见画面方向验收。猫侧向动作原表的收爪左右对调，统一收回实际伸出的那只爪。

## 网页素材验收

| 环节 | 测试内容 |
| --- | --- |
| 待机图 | 猫、狗各试一张清晰正面照。检查身份特征、正面趴卧、构图、背景和完整前爪 |
| 热区动作 | 同一待机图逐个生成左、中、右三段。检查动作到达目标区、主体稳定、首尾回到同一待机姿态 |
| 首次过场 | 先导结束接等待循环起始，检查相位与取景是否连贯，再检查等待段首尾衔接 |
| 模式切换过场 | 猫切狗、狗切猫分别检查目标角色入场、超越至居中、原角色退出 |
| 文件规格 | 实测分辨率、宽高比、平均帧率和时长。动作效果及首尾观感需目视复核 |
