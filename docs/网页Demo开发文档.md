# 宠物壁纸网页 Demo 开发文档

首轮在横屏浏览器中演示录入、生成、播放、切换与恢复。行为、热区和素材规格以 [PRD](宠物交互壁纸_PRD.md) 为准。页面入口、跳转和视觉参考[原型图](原型图.jpg)及 [MasterGo「页面 1」](https://mastergo.com/prototyping/210826940496035?fileOpenFrom=project&page_id=M)。

## 架构

建议采用前后端分层、同源部署的单应用架构。前端管理页面与播放状态，后端管理宠物档案、生成任务与成品。演示环境使用一个可访问的地址同时提供网页、API 和媒体资源。

| 部分 | 技术与职责 |
| --- | --- |
| [前端](../web-demo/frontend/README.md) | Vue 3、TypeScript、Vite 单页应用。负责录入表单、导航、生成进度、热区触摸和视频播放。 [Vue 快速上手](https://vuejs.org/guide/quick-start.html) |
| [后端](../web-demo/backend/README.md) | 单个 Python FastAPI 应用。提供网页构建产物、宠物档案 API、异步生成任务和媒体读取，管理供应商凭证。 [FastAPI 静态文件](https://fastapi.tiangolo.com/tutorial/static-files/) |
| 存储 | SQLite 保存宠物、任务状态、素材版本及上次成功显示记录。照片与视频保存为文件，数据库保存媒体元数据与引用。 |
| [公共素材](../web-demo/assets/README.md) | 提供 3 秒先导、7 秒追逐循环和模拟生成使用的猫狗样例素材。 |
| [算法验证](../algorithm-lab/README.md) | 独立运行可灵与 ComfyUI 实验。网页后端按需复用已验证的供应商调用、图片校验和媒体读取逻辑。 |

本地开发时可由 Vite 代理到 FastAPI。演示部署时构建前端静态文件，由同一站点提供页面和 API。单机首版使用一个任务执行实例，SQLite 持久化任务与远端任务 ID，进程重启后恢复查询。浏览器刷新后可继续查询已提交任务。 [Vite 构建说明](https://vite.dev/guide/build.html)

## 生成与播放

1. 每只宠物创建独立档案和任务。上传一张正面照，后端先存档再接受生成任务。重复提交同一次请求时返回原任务。
2. 网页提交后轮询任务状态。首轮播放一次 3 秒先导和一段 7 秒追逐。超过 10 秒后仍在生成时，只循环追逐段。素材就绪后的具体切出点沿用 PRD 待确认项。
3. ComfyUI 从原照生成待机图，再以该图约束首尾姿态。待机、左侧、中央和右侧四段视频的全部画面帧均由模型生成。校验后发布为一个可播放版本。猫狗同时提交时，先进入首套就绪的壁纸，另一只在列表中继续显示生成状态。
4. 壁纸页按 16:9 可见画面计算点击位置，34% 归中区，66% 归右区。按钮、弹层与留黑区不触发画布动作。生成中屏蔽热区与重复提交。停车时每次有效点击或实体按键触发都会立即从头播放对应动作，动作自然播完后回到待机。
5. 切换已有宠物时直接加载其素材。目标成功显示后再更新上次显示记录。切换或生成失败时恢复已有的成功壁纸。仅在首套生成失败且无历史壁纸时，按 PRD 待确认的首次失败流程处理。

前端分别管理生成任务和播放器状态。用户退出、返回或换宠后，延迟到达的请求结果只更新对应宠物的生成状态，当前壁纸按最新页面操作决定。预加载过场和即将播放的素材，实测 1080p、24 fps 视频的首帧与接缝。

## 接口草案

| 操作 | 接口与数据 |
| --- | --- |
| 档案 | `GET /api/pets` 列出宠物，`POST /api/pets` 新建档案，`PATCH /api/pets/{petId}` 保存资料。 |
| 生成 | `POST /api/generations` 提交宠物 ID、照片与幂等键并返回任务 ID。 |
| 进度 | `GET /api/generations/{jobId}` 返回排队、生成、就绪或失败的状态。就绪时附该版本的素材清单。 |
| 设置 | `POST /api/settings/unlock` 使用密码获取当前配置和短期令牌，`PUT /api/settings` 使用令牌保存生成设置。 |
| 恢复 | `GET /api/current-wallpaper` 读取上次成功记录，`PUT /api/current-wallpaper` 在可播放版本成功展示后保存记录。 |

首轮可在同一演示浏览器中按演示会话恢复记录。若需随实际车机用户切换档案，使用车机授权的用户标识。素材清单包括待机图、三个交互视频，以及 ComfyUI 生成的待机视频。各素材附格式、分辨率等信息，视频读取支持范围请求。

## 开发与验收

1. **模拟生成。** 用本地素材和可控任务跑通首次录入、双宠先后就绪、等待超时循环、切换、失败回退与刷新恢复。
2. **真实生成。** 在[生成设置](../web-demo/backend/README.md)选择 ComfyUI 或配置可灵，验收长任务恢复、重复提交、成品校验，以及同一宠物待机与三个交互动作的衔接。
3. **目标浏览器。** 在目标横屏浏览器复验照片选择、网页访问、触摸边界、全屏、静音播放和视频切换。网页内可用模拟状态验证停车和行驶时的交互规则。真实行驶限制、行车提醒优先级以及车机桌面壁纸需要平台接入并单独验收。
